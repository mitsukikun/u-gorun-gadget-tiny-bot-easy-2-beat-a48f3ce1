A tiny deterministic paper-trading bot for hourly Solana prices: it buys a symbol when its RSI(14) drops under 25 (deeply oversold) and sells when RSI rises over 55, sizing 24% of equity per buy, long only. Dev-window score (kit grade-local): Net PnL +515.54 USDC vs buy-and-hold −869.34, 34 trades, max drawdown 1.72%.
## Run it
```
python3 main.py
```
